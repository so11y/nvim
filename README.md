## Leader 组合键

which-key 按功能显示分组；所有当前 Leader 按键只在下表登记。

| 分组 | 按键 | 模式 | 功能 |
| --- | --- | --- | --- |
| 文件 `f` | `<leader>ff` | n | 文件搜索 |
| 文件 `f` | `<leader>fp` | n | 项目选择 |
| 搜索 `s` | `<leader>sg` | n | 全局文本搜索 |
| 搜索 `s` | `<leader>sr` | n, v | 搜索替换，默认当前文件 |
| 搜索 `s` | `<leader>sn` | n | 通知历史 |
| 搜索 `s` | `<leader>su` | n | 撤销历史 |
| 代码 `c` | `<leader>co` | n | 代码大纲 |
| 代码 `c` | `<leader>ch` | n | 折叠预览；无折叠时显示 Hover |
| 跳转 `j` | `<leader>jj` | n, x, o | Flash 跳转 |
| 跳转 `j` | `<leader>js` | n, x | Flash 选区 |
| 跳转 `j` | `<leader>jw` | n, x, o | 下一个子词开头 |
| 跳转 `j` | `<leader>jb` | n, x, o | 上一个子词开头 |
| 跳转 `j` | `<leader>je` | n, x, o | 子词末尾 |
| 窗口 `w` | `<leader>wv` | n | 垂直分屏 |
| 窗口 `w` | `<leader>ws` | n | 水平分屏 |
| 调试 `d` | `<leader>db` | n | 切换断点 |
| Git `g` | `<leader>gt` | n | LazyGit |
| Git `g` | `<leader>gn` | n | Neogit |
| Git `g` | `<leader>gd` | n | CodeDiff 差异 |
| Git `g` | `<leader>gh` | n | Git 历史 |
| 诊断 `x` | `<leader>xf` | n | 当前文件诊断 |
| 诊断 `x` | `<leader>xx` | n | 工作区诊断 |
| 退出 `q` | `<leader>qq` | n | 退出 Neovim |

再次按代码预览键可进入浮窗，`Esc` 关闭。子词移动识别驼峰、下划线和数字边界；可配合 `v`、`d`、`c` 选中、删除或修改，例如 `d<leader>je`。

VSCode 的文件搜索、全局搜索、替换、分屏、大纲和 Hover 调用宿主；其他插件功能依环境启用范围使用。

## LSP 与诊断

`gr` 是分组前缀，输入完整组合触发操作；这些键不用空格。VSCode 对应入口调用宿主语言功能。

| 按键 | 功能 |
| --- | --- |
| `gd` | 定义 |
| `grr` | 引用 |
| `gri` | 实现 |
| `grt` | 类型定义 |
| `grn` | 重命名 |
| `gra` | 代码操作，支持普通及可视模式 |
| `grx` | Neovim 原生 CodeLens 操作，需语言服务器提供 |
| `[x` / `]x` | 上一条 / 下一条诊断 |

Vue 标签重命名交给 `vue_ls`，代码符号交给对应服务器。HTML/Vue 标签菜单支持删除、去外层、空标签转换和 Emmet 包裹；包裹操作确认后才修改文本。

## 编辑与移动

| 按键 | 模式 | 功能 |
| --- | --- | --- |
| `<Enter>` | n / i | 在光标后进入插入 / 换行或确认补全 |
| `<Esc>` | n | 关闭 Hover、取消多光标或清除搜索 |
| `J` / `K` | n | 下翻 / 上翻半页 |
| `gh` / `gl` | n, v | 行首非空白处 / 行尾 |
| `G` / `gg` | n, v | 文件开头 / 文件结尾 |
| `<A-a>` | n | 全选 |
| `<A-s>` | n, i, v | 保存 |
| `<A-z>` / `<A-y>` | n, i, v | 撤销 / 重做 |
| `<A-u>` / `<A-i>` | n | 后退 / 前进跳转位置 |
| `<A-j>` / `<A-k>` | n, v | 向下 / 向上移动行或选区 |
| `<A-d>` | n, i / v | 删除行 / 删除选区 |
| `<A-x>` | n / v | 剪切行 / 剪切选区到系统剪贴板 |
| `<A-c>` | v | 复制到系统剪贴板 |
| `<A-v>` | n, i, x, c | 粘贴；可视模式替换选区并保留剪贴板 |
| `<A-/>` | n, v | 切换行注释 |
| `gcO` / `gco` / `gcA` | n | 上方 / 下方 / 行尾添加注释 |
| `<A-F>` | n, i | 格式化，即 Alt+Shift+F |
| `<A-f>` | n | 当前文件内搜索 |

`u`、`<C-r>`、`dd`、`s` 及 PageUp/PageDown 已禁用。普通删除 `x/c/d` 使用黑洞寄存器，不覆盖剪贴板。

保存与手动格式化使用同一个 LSP 入口；独立编辑器使用 efm 或 rust-analyzer，VSCode 使用宿主格式器。项目格式配置优先，失败显示通知并保留原内容。

## 多光标

独立编辑器使用 vim-visual-multi 实时同步输入；VSCode 使用宿主多光标及 vscode-multi-cursor.nvim。

| 按键 | 模式 | 功能 |
| --- | --- | --- |
| `gb` | n, x, i | 选中当前词 / 选区，再按选择下一个相同内容 |
| `<A-J>` / `<A-K>` | n, x, i | 向下 / 向上添加光标，即 Alt+Shift+J/K |
| `mc` | n, x | 手动添加光标；独立编辑器中再次按下可移除 |
| `mm` | n, x | 独立编辑器中启用全部光标并一起移动 |
| `mi` / `ma` | n, x | 在所有光标前 / 后插入 |

普通模式按 `Esc` 退出多光标；插入模式先退出插入，再按一次退出多光标。独立编辑器中输入、退格和换行实时同步，多光标期间暂停补全与自动括号，退出后恢复。

## 语法选区与文本对象

可视模式 `Enter` 逐级扩选，`Backspace` 按原路径回缩；VSCode 使用宿主选区。

下表内部 / 整体对象用于 `x/o`，跳转用于 `n/x/o`。例如 `daf` 删除整个函数，`vis` 选中语句内容。

| 对象 | 内部 | 整体 | 上一个 | 下一个 |
| --- | --- | --- | --- | --- |
| 函数 / 方法 | `if` | `af` | `[f` | `]f` |
| 循环 | `il` | `al` | `[l` | `]l` |
| 条件分支 | `id` | `ad` | `[d` | `]d` |
| 方法调用 | `ic` | `ac` | `[c` | `]c` |
| 参数 | `ia` | `aa` | `[a` | `]a` |
| 语句 / 声明 | `is` | `as` | `[s` | `]s` |
| 成对括号 | `ib` | — | `[b` | `]b` |
| 成对引号 | `iq` | — | `[q` | `]q` |

`ib/iq` 由 mini.ai 提供，优先当前行内包含光标或选区的对象，否则选择下一个，找不到时扩大到前后 50 行。`[b/]b`、`[q/]q` 分别跳到括号、引号的起始位置；括号支持嵌套，`2]b` 等同于连续跳两次。光标位于括号字符时，`i%` 可选其内部内容。

`;` 重复上次结构跳转或 `f/F/t/T` 查找，`,` 反向重复；`f/t` 向后查找字符 / 字符前，`F/T` 向前查找字符 / 字符后。结构跳转覆盖同名原生 `[/]` 组合。

## Git 操作

独立编辑器使用 LazyGit、Neogit 管理 Git，CodeDiff 查看差异。Neogit 为英文菜单；CodeDiff 的兼容版本由插件配置和锁文件固定。

CodeDiff 中 `]c` / `[c` 切换差异块，`]f` / `[f` 切换文件，`q` 关闭视图。Neogit 的菜单组合按顺序输入，例如 `b c`。

| Neogit 按键 | 功能 |
| --- | --- |
| `y` | 分支列表 |
| `b c` / `b l` | 选择起点创建并切换分支 / 切换分支 |
| `m m` | 合入分支 |
| `s` / `u` | 暂存 / 取消暂存当前文件或差异块 |
| `c c` | 编辑提交信息，连续两次 Ctrl+C 完成提交 |
| `f a` | 抓取所有远程 |
| `p u` / `P u` | 从上游拉取 / 推送到上游 |
| `d d` | CodeDiff 查看当前文件或提交差异 |
| `?` | 操作菜单 |

## 补全与调试

| 按键 | 模式 | 功能 |
| --- | --- | --- |
| `<A-q>` | i | 显示 / 隐藏 Blink 补全 |
| `<A-j>` / `<A-k>` 或上下方向键 | i, c | 下一条 / 上一条补全 |
| `<Tab>` | i, c | 显示 / 确认补全；插入模式可跳片段或展开 Emmet |
| `<S-Tab>` | i | 回到上个片段位置 |
| `<F5>` | n | 启动 / 继续调试；Rust 首次选择 Cargo 调试目标 |
| `<F10>` / `<F11>` / `<F12>` | n | 单步越过 / 进入 / 跳出 |

Node debugger 暂停若弹出菜单，选择 Resume stopped thread。
